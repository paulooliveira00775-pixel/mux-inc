# Mux — mux.inc

A lightweight, mobile-friendly homepage for **Mux**, a fictional technology brand exploring imagined devices, thoughtful design, and playful product concepts.

> Mux is a fictional brand project. The products, concepts, specifications, and visuals described here are imaginative creations and are not products currently for sale.

## Preview

The site is a simple static page built with plain HTML and CSS. No framework, build step, API key, or JavaScript dependency is required.

## What's included

- Brand introduction and story
- Three brand principles
- A clear note explaining that Mux is fictional
- TikTok follow link for [@mux.inc](https://www.tiktok.com/@mux.inc)
- Responsive layout for phones, tablets, and desktop
- Basic page metadata and a custom SVG favicon

## Run it

Open `index.html` in a browser, or publish the repository with GitHub Pages.

## Publish with GitHub Pages

1. Create a public repository on GitHub (for example, `mux-inc`).
2. Upload `index.html`, `style.css`, and the `assets` folder to the repository root.
3. Open **Settings → Pages**.
4. Under **Build and deployment**, choose **Deploy from a branch**.
5. Select the `main` branch and `/ (root)`, then save.
6. After deployment, GitHub will show the published site URL in the Pages settings.

## Update the page

- Edit the text and sections in `index.html`.
- Change colors and layout in `style.css` using the CSS variables near the top.
- Update the TikTok URL in `index.html` if the account changes.
- Put brand images in `assets/` and reference them from the HTML.
